# GP LAW LLC website

Static website. No build tools, installation, dependencies, or API keys required.

## Files
- index.html: page content
- assets/styles.css: responsive styles
- assets/attorney.jpg: supplied portrait
- .nojekyll: static publishing marker

## Preview
Open index.html in a browser with the assets folder beside it.

## Publish on GitHub Pages
1. Unzip this package.
2. Upload index.html, assets/, .nojekyll, and this README into the repository root. Do not upload only the ZIP or put the files inside an extra folder.
3. Commit the files to main.
4. Open repository Settings > Pages.
5. Choose Deploy from a branch, main, / (root), then Save.
6. GitHub Pages will display the published site address once deployment completes.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Editing
Edit index.html for wording, phone, and email. Edit assets/styles.css for colors and layout. Replace assets/attorney.jpg to change the portrait.

## Before launch
The firm should verify attorney identity, photo usage permission, practice areas, free consultation terms, and all advertising text. No location, bar admissions, or credentials have been invented. Add any applicable jurisdiction-specific disclosures before publishing.

## Contact behavior
Call buttons use tel: links. Email links open the visitor's email application. There is no contact-form backend or database.

No domain has been configured. Add a custom domain through GitHub Pages settings if desired.
